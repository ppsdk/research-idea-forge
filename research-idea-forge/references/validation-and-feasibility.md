# 判别性验证、可行性和候选状态

本文件服务完整开发或明确请求的验证/资源计划。概念评审不以此处执行要求给想法扣分；方案与已执行证据分开。

## 一、最小证伪契约

一次最小检验要说明：

```text
中央机制主张：
一个承重变量：
改变这一变量的干预：
尽量保留什么容量/数据/预算/状态：
一个下游指标及预期方向：
机制被破坏时的回落预测：
替代解释和区分方式：
什么结果使主张被否定/收窄：
实际执行状态、输入、日志和结果或计划：
```

不能只定义一个内部指标，而干预后该指标按定义下降；必须连接真正的下游目标。控制不能同时破坏任务合法性而后声称证明了独有机制。

## 二、选择匹配控制

| 主张 | 合适控制方向 |
|---|---|
| 源—目标映射重要 | 朴素迁移、合理错误映射、破坏对应但保留预算 |
| 结构先验重要 | 无结构、弱化/错误/随机先验，容量匹配 |
| 接口耦合重要 | shuffle/swap/detach/stale，保留外围组件 |
| 状态自适应有效 | 同预算固定或状态无关分配，信号打乱 |
| 反馈有效 | 无反馈或受控延迟，匹配初始状态与计算 |
| 数值替代更高效 | 完整路径成本、相同质量、朴素同成本替代 |

明确控制仍保留哪些约束。复杂系统可先用 frozen schedule、fresh-prefix 或 matched-state replay 解决历史路径混淆。不是每个候选都要全部控制。

## 三、最小研究原型

可以先做数值 dry run、数据切片、冻结模型探针、匹配复现或单接口替代，不强制完整训练。记录基线版本、数据、种子、预处理、预算、指标与失败日志。

程序报错先诊断实现；程序正确但预测失败要收窄科学主张，不无限调参掩盖。小原型成功仅支持当前条件。多种子、区间、配对与泛化范围应与主张风险和后续阶段相称。

## 四、实现审计

每个步骤写输入/输出、shape、模块、训练/推理/执行后、梯度、所需标签/传感/模拟器和回退。代码存在时从配置到最终消费者追踪实际路径。

不能用“会加入一个 head”填补关键接口未知。给出具体建议接口并标为提案。静态 inspection 与真实运行分开。

## 五、资源与端到端成本

按用户真实资源估算：数据/标签、模型训练/微调、前向/反向/求导、矩阵构造与求解、缓存与通信、评估及重置。GPU-day、API-dollar 等数字没有依据时给估算公式与待补输入，不编数值。

部署或效率主张包含最慢/尾部延迟、内存、完整控制路径与失败回退；局部模块变快但总延迟变慢不能写总效率改善。

具身研究区分离线代理、预测结果、模拟器执行和真实机器人结果；oracle/privileged state 与未来信息不能用于部署主张。安全与恢复的测试范围随实际任务，而不把新颖算子视为安全保证。

## 六、开发检查 G0–G7

| 项 | 问题 |
|---|---|
| G0 目标 | 问题/机会及重要性是否具体、有依据 |
| G1 机制 | 承重变量与作用路径是否可解释 |
| G2 新颖性 | 最近工作是否已执行相同关键步骤 |
| G3 自洽 | 信息、依赖和运算是否可执行 |
| G4 可证伪 | 负控制是否能否定中央主张 |
| G5 可行性 | 用户资源和部署条件是否允许该路径 |
| G6 主张对齐 | 指标和比较是否检验所说贡献 |
| G7 入口有效 | 映射、先验、接口或优化契约是否成立 |

相关项标“已规定 / 有依据 / 失败 / 未核验”。区分方案完整、来源支持、数值自洽和实证效果；计划不能通过实证 gate。此处不是概念评分体系，也不是投稿就绪评审。

## 七、状态与升级

| 状态 | 含义 | 下一步 |
|---|---|---|
| 论文级开发候选 | 概念、可核验差异与路径足以投入下一次研究检验 | 检验中央机制，尚不声称有效或可投稿 |
| 探索种子 | 有意义直觉，关键机制/差异未闭合 | 最小建模、来源核验或判别检验 |
| 工程优化 | 质量成本改进，普适科学解释未建立 | 匹配全路径成本与泛化条件 |
| 分析线索 | 现象或诊断有价值，干预方法未定 | 区分竞争解释 |
| 基线/消融资产 | 不独立创新但能辨明另一主张 | 保存可复用实现与条件 |
| 暂缓假设 | 来源、条件、资源或逻辑暂不可满足 | 写最小解锁条件 |

未完成实验不自动降低概念质量。新颖性未核验限制“已确认新颖”这类措辞，而不需要删除有用候选。

## 八、停止与保留

同一硬问题两次定向修复仍失败时停止推广原主张，选择收窄、真正重构、转工程优化或暂缓。记录问题、已试修复、证据和最小解锁条件，保留失败原型和负结果。

局部修复有效或新信息改变问题时可以继续；避免把不同问题机械算作同一个两次计数。不用预算耗尽冒充科学失败，也不因已有投入宣称应该继续。
