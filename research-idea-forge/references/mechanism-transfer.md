# 机制迁移：从相似词汇到可保持的结构

## 一、对象与共有结构

迁移可跨任务、模型家族、机器人本体、控制方式、数学领域或学科。先找资源分配、部分观测估计、等变性、误差反馈、投影、组合搜索、层次分解或多尺度时间等共有结构。

“都叫 attention / memory / policy”不构成结构同构。源任务效果好不证明目标适用。目标已有同算子而仅改术语或数据集时，通常没有新增机制差异。

## 二、源机制卡

核验实际来源的方法或代码，抽出最小机制原语：

```text
来源及阅读位置：
源问题与目标：
必要假设：
输入状态与可用信息：
核心操作、更新式或约束：
为什么这一操作产生作用：
被保留的性质：
证据、成本、失败条件：
```

分离机制与训练配方、后处理、规模、评价优势。只有摘要时提出映射猜想，不说源算法已逐步验证。

## 三、目标结构对应

| 源对象 | 目标对象 | 对应关系 | 保留/破坏的性质 | 时刻与量纲 |
|---|---|---|---|---|
| 状态 | 观测/内部状态 | 映射或编码 | 可辨识、Markov 等 | 时间、坐标 |
| 决策 | 动作/token/记忆/预算 | 实际操作接口 | 连续/离散、可行性 | 推理可得性 |
| 目标 | 任务损失/质量成本 | 标准化或替代 | 排序、风险敏感性 | 单位与估计误差 |
| 约束 | 目标限制 | 对应与不对应项 | 硬/软、等式/不等式 | 生产者 |
| 更新 | 训练/反馈 | 频率与梯度变化 | 收敛/不变性条件 | 执行前/后 |

不能映射的对象写缺口。多模态、高维动作、有限时域不是自动理由，需要说明怎样破坏源条件。

## 四、保留性检验

合适时使用：

```text
phi(M_source(z)) ≈ M_target(phi(z))
```

说明 `phi`、两算子、比较域、误差度量、适用输入及误差为何可接受。这不是自动成立的定理。不必要求可逆；多对一映射要解释丢失的信息是否影响目标。

可检验：排序/相对代价、约束/可行性、等变性、时间/因果顺序、梯度/无偏性/误差界、组合操作语义。选择真正需要保留的性质并核对前提。

没有必要保留属性时降为类比性探索种子，原型可做但不宣称理论支持。

## 五、必要适配成为具体方法

沿破坏的源条件改变表示、目标、约束、反馈、求解器、采样或更新。每项适配回答：

1. 哪个目标条件迫使变化？
2. 新增哪步运算，输入/输出/时间/参数是什么？
3. 与直接搬用源方法有何不同？
4. 删除该步骤或使用错误映射，哪种作用应消失？

不能只写“考虑领域特性”“加入网络”。源方法可直接套用时迁移可能是应用/工程贡献；核验目标最近工作再决定贡献类型。

## 六、迁移专用碰撞检索

- 源领域：原始机制、必要条件、后续变体、旧名称。
- 目标领域：直接问题、同运算、相似反馈或约束接口。
- 桥接集合：跨域迁移、不同术语的数学等价方法、朴素应用。

比较运算而非名称。机制祖先不限近期年份；最新工作检查抢先风险，较早工作排除重新命名。无具体来源时写“机制族类比，来源未核验”，不编论文。

## 七、控制与负迁移

按候选选择最小比较：目标强基线、朴素源方法迁移、完整适配、破坏映射/先验/接口的控制。尽量保持容量、数据、预算；明显不合法的动作只能证明合法性重要，不能证明映射独特。

负迁移条件包括：目标不满足源假设、多对一丢失必要信息、反馈延迟、单位/坐标/尺度错配、映射成本过高、噪声/分布改变目标排序、源约束排除目标有效解。选择适用条件，不全列配额。

“适配提高成绩”只证明总作用。映射机制需要匹配路径和使方法回落的判别性控制。

## 八、交付契约

```text
源机制及位置 → 目标条件 → 对象映射 → 保留属性 → 破坏的条件
→ 最小适配 → 最近目标工作差异 → 朴素迁移基线
→ 破坏映射对照 → 负迁移条件 → 证据状态与下一步
```

完整开发回填现有 idea 卡；只要迁移建议交付映射卡。概念审视中对照只是可判别性说明，不视为必须完成的实验。
