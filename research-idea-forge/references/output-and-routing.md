# 输出、范围与技能协作

## 一、按请求选产物

- 短任务：直觉、实际机制变化、最接近工作或未核验边界、承重假设、当前状态和最小下一步。
- 迁移建议：源机制—目标结构映射卡，不自动生成完整论文或大实验矩阵。
- 数学构建：变量/信息/目标/约束、必要推导、算法落点、边界与判别性预测。
- 完整开发：完整 idea 卡；没有资料的字段标未知/待核验，不伪造内容。
- 多候选：覆盖全部请求对象，用相同条件比较；除非明确要求全部深化，否则深入主线。
- 仅概念评审：明确使用本技能时由本技能直接判断；否则遵循已选评审路由。不要输出完整实验规划、资源门槛或因为未做实验而否定概念。
- 局部追问：只改相应字段及其依赖；不要每次重新输出全流程。

顺序先讲直觉，再讲机制、数学、实现、检验和边界。只在有用时保留详细符号；不把内部 gate 和流程日志塞入论文正文。

## 二、完整 idea 卡字段

1. 名称及一句话主张。
2. 入口、研究目标、贡献类型与范围。
3. 已核验文献、用户证据及访问边界。
4. 失败/机会/原型现象或优化目标。
5. 承重机制假说。
6. 候选比较（只在实际比较多入口时）。
7. 方法步骤、数据流、训练/推理和信息时刻。
8. 数学对象、推导、假设及符号到代码。
9. 作用理由与竞争解释。
10. 最近工作及关键运算差异，以及主贡献和受益者。
11. 实现路径、真实资源条件和缺口。
12. 最小证伪、负控制和停止条件。
13. 基线/指标/泛化边界（开发请求适用）。
14. 风险、负迁移、退化及失败回退。
15. 当前状态与升级条件。
16. 已核验、推断、提案和未完成工作的区分，以及所需/现有/缺失证据与主张边界。

可复用 [中文模板](../assets/idea-card.zh.md)，字段可合并为连贯叙述，不强制每项独立标题。无关字段省略并说明范围。候选的来源映射或数学契约可插入相应字段。

## 三、保持唯一主产物

优先已有项目规范和候选文件，原位更新 canonical idea。原始结果、提交版本、对比基线和来源证据保留；比较新旧版本用同一范围和口径。

默认由本技能维护最终 idea 卡。用户或项目已指定 CCFA/其他主责时保留该主责；没有声明时不因安装某技能自动转交。沿用同一份文件是避免版本分叉的约定，不限制本技能直接交付。

没有文件交付需要时直接在聊天中回复。需要落盘则遵守宿主 outputs/work 规则；原始文献存在所属记录中，idea 卡只引用，不复制整套语料。不要按每个辅助技能建立一份互相冲突的主 idea。

## 四、协作边界

| 方法/主责 | 何时使用 | 不应自动带入 |
|---|---|---|
| 本技能 | 默认独立构建、内置候选审视、贡献收敛与最终 idea 卡 | 未请求的全文和实际实验 |
| `ccf-idea-optimizer` | 明确选择 CCFA 主责，或需要其方向优化方法 | 强制转交和另一份主 idea |
| `ccf-idea-reviewer` | 未指定技能的单独概念评审，或需要额外概念审查 | 实验完整性和投稿就绪 |
| CCFA 文献技能 | 文献地图、检索和来源记录 | 下游全文写作 |
| `idea-spark` | 深检索、模式参考、自洽、碰撞、可实现性审查 | 固定分支覆盖、工厂预算、与当前请求不符的强制瓶颈前置 |
| Supervisor-Skills | 已吸收五维收益、贡献类型定位、致命问题和修复、问题探针；额外深调研按需调用 | 第二套评分、硬套生命周期或默认 GPU 门槛 |
| PaperSpine | 已吸收主贡献—具体缺口—方法响应—证据—边界契约 | 仅找点时的 Web 配置、全文/模板/排版 |

真正运行辅助技能前读取其安装文件和必要依赖。辅助只当参考时明确说明方式，不能称整套 workflow 已完成。配置缺失且不是当前必要产物时选择现有工具完成，不以安装或额外付费阻塞构思。

研究多阶段计划交给 `ccf-pipeline-orchestrator`；完整实验协议、实现与运行、全文写作、图表、完整论文审稿、投稿和 rebuttal 只有请求包含时接手。既有联合任务授权允许连续执行，不为常规交接重复征求同意。

## 五、治理与来源

本技能整理用户 `research-idea-agent.md` 的多入口方法、迁移契约、结构先验、数学落点、碰撞、自洽、证伪和状态规则。本次更新依据用户请求改为可独立负责最终产物，并吸收 Supervisor-Skills/PaperSpine 的选择性方法。明确已有项目主责时仍保留该归属。

具体吸收与调整见 [贡献与候选选择](contribution-and-selection.md)；不复制上游不适用于当前范围的固定阈值、实验门槛或文件/工作台要求。

这些是方法规则；不把源规则中的示例或口号视为当前领域事实。Supervisor/PaperSpine 的实际细节以其当前安装文件为准，本技能无需它们存在也能完成自身构建方法。

发生冲突时以当前请求和更具体用户规则为准。仅方法差异不触发额外审批；涉及真实资源或外部行动时按宿主权限与已获授权执行。
