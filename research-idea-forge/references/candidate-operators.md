# 多入口构思与机制操作

入口产生候选，共同审查决定主张强度。不要混为“每个想法先做完实验才允许存在”。操作是选择工具，不是数量、分支或顺序配额。

## 一、选择入口

| 入口 | 从什么开始 | 第一份有用输出 |
|---|---|---|
| 科学问题重构 | 失败、未解释属性、评价不匹配 | 有条件和比较对象的研究问题 |
| 机制迁移 | 邻域机制和共有结构 | 源—目标映射与适配 |
| 数学构建 | 决策、误差、约束、信息、分配 | 可计算对象及新增运算 |
| 结构先验 | 几何、动力学、拓扑、对称、因果、时序 | 插入计算的先验及失效条件 |
| 机制组合 | 两机制处理不同职责 | 明确且必要的接口 |
| 优化 | 质量、效率、内存、鲁棒或数据成本 | 固定约束下的质量成本改进 |
| 设计/经验 | 固定惯例、算子、错误簇或异常 | 改变的变量与判别性预测 |

对明确候选局部深化；对欠定方向提出真正不同的候选。差别来自运算、约束、信息或机制，不是命名。

## 二、机制操作库

### 解放固定设计变量

寻找惯例固定的 horizon、chunk 长度、rank、记忆长度、更新频率、迭代次数、分辨率或路由阈值。说明为何只是设计选择，怎样由可用状态或不确定性决定。

需要：调节信号的时刻、成本、稳定性、预算守恒及匹配固定策略。改变变量同时增加数据/算力时不能只归因于自适应。

### 注入结构先验

将先验写入表示、算子、目标、可行集合或推理。例如等变性、稀疏、可达性、接触拓扑和时间顺序。

需要：来源、正确条件、构造保证与学习部分、错误/随机/弱化先验及容量匹配无结构替代。估计物理关系不等于真实物理保证；保证应说明误差与可行性条件。

### 制造内部监督

由时序/跨视角一致性、执行残差、循环一致性、模型分歧、置信度或自生成筛选得到信号。

需要：与目标的联系、捷径解、训练/部署边界、标签与生成成本。模型置信度可能只反映自洽，预测价值需验证。

### 从失败而非均值学习

分类失败，再改变采样、记忆、表示、路由或恢复。确认分类不是结果的事后命名，指出信号最早何时可见。

需要：结果出现前的预测性、类别定义、误报成本和同资源统一处理对照。平均指标外可形成分析贡献，但无干预不能直接归因。

### 替换算子或表示

把昂贵/不适配操作改为具有必要性质的近似、投影、低秩表示、稀疏选取或闭式更新。

需要：保留性质、近似误差、失效状态、全路径成本、同成本朴素替代。闭式不自动更快；分解、求导、矩阵构造也计成本。

### 诊断再设计

匹配比较分离容量、数据、调参、评估或信息泄露，定位承重变量，再做最小替代。可在提出候选后使用，不是迁移、先验或数学构建的强制前置。

### 改变假设、约束或信息

定位不可辨识、多解、延迟、分布混杂、部分观测或训练—评估错配中的承重假设。可放松、估计、改目标或加可用信息。

需要：新增信息是否合法、哪些结论失去保证、与已有处理的比较。额外标签和 privileged state 属于设置变化，不能隐藏。

## 三、组合契约

“A+B”需要新关系，而非两组独立功能：

| 关系 | 必须说明的接口 |
|---|---|
| 串行 | A 产生 B 必须使用的状态、表示或约束 |
| 反馈 | B 的实际结果更新下一轮 A |
| 条件 | 可解释信号选择 A/B，何时可得 |
| 分解 | 对应不同误差项或职责 |
| 统一 | 同一目标/算子包含两部分为特殊情形 |
| 多尺度 | 局部/全局在何时、用什么状态交互 |
| 约束 | 提案如何投影或限制可行性 |

接口要有生产者、消费者、量纲、时间、梯度和失效处理。打乱、互换、延迟或断开接口后作用还在时，收窄耦合解释。不为组合形式增加无用组件。

## 四、五维与重大问题探针

方向欠定时问：更高（效果）、更快（效率）、更强（鲁棒/泛化）、更省（数据/部署成本）、更广（跨域/统一）哪项最有价值。选主目标及必要支持目标，不强制雷达评分。

问题层面创新可问：哪条隐含假设失效？哪种重要问题被评价方式掩盖？技术变化提供什么条件？解决后改变谁的决策？答案产生假设，不证明颠覆性或新颖性。

## 五、从候选到主线

```text
入口 | 目标适配 | 新增运算 | 映射/先验/接口 | 破坏机制的控制 |
最近工作差异及覆盖 | 资源条件 | 当前状态
```

比较真正使用的入口，选可解释、可分辨主线，备选留同一记录。差异未核验时标探索种子；已有实现但只局部提速可为工程优化，不强写新范式。
